Display units and precision (7.12.b)

Calculation precision and display precision are separate (4.18). Every figure is computed and stored as an exact decimal; the screens show currency at whole units, percentages to one place, ratios to four and discount factors to six, and any figure that had to be rounded to be shown carries its full stored value in a tooltip (4.19).

These are fixed rather than configurable. A per-reader precision setting would mean two people reading the same model see different numbers and cite them to each other.
